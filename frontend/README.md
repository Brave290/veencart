# Frontend

This folder owns the Next.js presentation layer.

- `src/app/` — routes, layouts, loading and error boundaries
- `src/components/` — brand, motion and reusable UI components
- `src/lib/` — browser-safe design tokens, motion helpers and service definitions

Run project commands from the repository root so the shared Next.js, TypeScript
and test configuration is used. Keep server-only database access and migrations
in `../backend/`.
